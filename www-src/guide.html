01 — התקנה והפעלה

התקנה והפעלה

שלבי ההתקנה וההפעלה של כל רכיבי המערכת — Frontend, Backend AI, סוכן Windows וסוכן Desktop.

📦

דרישות מקדימות

  • Node.js — גרסה 16 ומעלה (לשרת הקבצים הסטטי)
  • Python 3.9+ — להפעלת שרת ה-AI והסוכנים
  • pip — מנהל חבילות Python
  • Git — לשכפול הפרויקט מ-GitHub
  • ANTHROPIC_API_KEY — מפתח API של Claude (לפיצ׳רים של AI)
1

שכפול הפרויקט מ-GitHub

שכפלו את המאגר לתיקיה מקומית:

git clone https://github.com/danielleites/Symbols-for-copy-28.02.git cd Symbols-for-copy-28.02
2

הפעלת Frontend

הרצת שרת סטטי לאפליקציה. אם אין לכם serve, התקינו אותו:

npm install -g serve serve . -l 8080 --no-clipboard

האפליקציה תהיה זמינה בכתובת http://localhost:8080

3

הפעלת שרת AI Backend

התקנת תלויות Python והפעלת שרת FastAPI:

pip install fastapi uvicorn anthropic python ai-server.py

השרת יעלה על פורט 8000 כברירת מחדל.

4

הפעלת סוכן Windows

אפליקציית System Tray שמנטרת שינויים בקבצים:

cd windows-agent pip install -r requirements.txt python piv_agent.py
5

הפעלת סוכן Desktop

ממשק גרפי מלא (Tkinter) עם חיבור ישיר ל-Claude API:

# הגדרת משתנה סביבה export ANTHROPIC_API_KEY="sk-ant-..." python desktop_agent.py

דורש את משתנה הסביבה ANTHROPIC_API_KEY.

02 — מצבי עבודה

מצבי עבודה

ארבעה מצבי עבודה ייחודיים המאפשרים פיתוח, בדיקות, ניתוח וניווט בנתוני AF.

🖥️

מצב אמולטור

Ctrl+1

הרצת 63 סמלי PI Vision בסביבת אמולציה בדפדפן. הסמלים נטענים ב-iframe עם תמיכה מלאה ב-DevTools וכלים נוספים.

תכונות עיקריות

  • DevTools מובנה — F12 לפתיחה/סגירה
  • דפדפן AF — F9 לגישה מהירה לנתוני AF
  • חיפוש סמלים — סינון מהיר לפי שם
  • בקרת גודל — S / M / L / Full
  • רענון iframe — Ctrl+R

קטגוריות סמלים

מוגבלות גרפים מדדים ניטור נתונים ניווט
🔍

מצב בדיקת QA

Ctrl+2

ניתוח קוד אוטומטי וזיהוי בעיות בסמלים. כולל ניתוח סטטי (HTML/JS/CSS), זיהוי שגיאות Runtime, ומעקב רגרסיה.

יכולות

  • ניתוח קוד אוטומטי — HTML, JavaScript, CSS
  • זיהוי שגיאות Runtime
  • צ׳קליסט בדיקות ידניות
  • אינטגרציה עם GitHub — טעינת סמלים מהמאגר
  • ייצוא תוצאות — PDF / CSV
  • מעקב רגרסיה — השוואה לבדיקות קודמות
  • גרף תלויות רשת — ניתוח קשרים בין רכיבים
🔗

מצב משולב — אמולטור + QA

Ctrl+3 — מומלץ

המצב המומלץ לעבודה יומיומית. האמולטור מוצג במסך הראשי ובדיקות QA רצות ברקע. תפיסת שגיאות בזמן אמת.

כיצד זה עובד

  • האמולטור מוצג בחלק הראשי של המסך
  • בדיקות QA רצות ברקע באופן אוטומטי
  • F10 — פתיחה/סגירה של פאנל ה-QA
  • גשר postMessage — תפיסת שגיאות בזמן אמת מה-iframe
  • זיהוי דינמי של שגיאות בסמלים רצים
🌐

דפדפן AF

Ctrl+4

דפדפן עץ מלא לנתוני PI AF עם חיפוש, ניווט היררכי ופאנל פרטי Attribute.

עוזר AI

04 — סוכן AI אוטונומי

סוכן AI אוטונומי

מערכת סוכנית שמבצעת משימות QA באופן אוטונומי — סריקה, תיקון, יצירת סמלים ואופטימיזציה.

🤖

פתיחת הסוכן

לחצו על אייקון הרובוט (🤖) בפינה השמאלית העליונה. הסוכן כולל 3 לשוניות: Dashboard (סטטיסטיקות משימות, כפתור סריקה כוללת), Actions (6 פעולות), ו-Results (תוצאות, ציונים, תצוגת קוד).

6 פעולות הסוכן

🔍

סרוק הכל

סריקת QA אצוותית לכל 63 הסמלים. הסוכן עובר סמל-סמל ומדווח על ממצאים.

🎯

סרוק סמל

סריקה מעמיקה לסמל ספציפי — ניתוח קוד, בדיקות תקינות, וזיהוי חולשות.

🔧

תקן קוד

תיקון אוטומטי עם Claude — כולל גיבוי אוטומטי של הקוד המקורי לפני כל שינוי.

🆕

צור סמל

יצירת סמל חדש מתיאור טקסטואלי — הסוכן מייצר קוד HTML/JS/CSS מלא.

⚡

אופטימיזציה

שיפור ביצועים, הקטנת גודל קוד, ושיפור נגישות של סמל קיים.

🧠

משימה חופשית

מצב אוטונומי מלא — Claude מחליט אילו כלים להפעיל בהתאם לתיאור המשימה.

05 — סוכן Windows

סוכן Windows

אפליקציית System Tray שמנטרת שינויים בקבצי סמלים ומפעילה סריקות אוטומטיות.

🖥️

סוכן System Tray — piv_agent.py

  • File Watcher — מנטר שינויים בתיקיית הסמלים
  • סריקה אוטומטית — מפעיל סריקת QA בכל שינוי קובץ
  • דיווח — שליחת דו״חות לשרת API
  • יושב ב-System Tray — לא תופס מקום במסך
🖱️

סוכן Desktop — desktop_agent.py

ממשק גרפי מלא עם Tkinter. חיבור ישיר ל-Claude API — ללא צורך בשרת.

  • ממשק GUI מלא עם Tkinter
  • 5 פעולות + מצב Auto-Scan
  • חיבור ישיר לקלוד (דורש ANTHROPIC_API_KEY)
  • יצירת דו״חות HTML
⚙️ הגדרות תצורה (Configuration) ▼

ניתן להגדיר את הסוכנים באמצעות קבצי תצורה:

  • config.yaml — הגדרות כלליות לסוכן System Tray
  • agent_config.yaml — הגדרות ספציפיות לסוכן Desktop
  • כתובת שרת, תיקיית סמלים, רמת Logging, מרווחי סריקה
